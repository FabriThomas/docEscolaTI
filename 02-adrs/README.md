# Fase 2 — Pré-Código: Consolidação dos 27 ADRs (Architecture Decision Records)

O projeto **Steely** possui **27 ADRs (`ADR-01` a `ADR-27`)** revisados cruzadamente entre os 5 integrantes da equipe, cobrindo Visão Computacional, Segurança/LGPD, Regras Financeiras/Escrow, Banco de Dados, Backend/API, Testes/SDLC, Frontend Web e Mobile Android Offline-First.

Todos os 27 ADRs estão disponíveis em **Markdown (`.md`)** na pasta [`md/`](md/) e em **PDF padronizado (`.pdf`)** na pasta [`pdf/`](pdf/).
