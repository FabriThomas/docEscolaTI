## Glossário de identificadores

Os documentos se referenciam por códigos. Esta tabela explica cada um:

| Código | Significa | Onde é definido |
|---|---|---|
| `RF-01` … `RF-22` | Requisito funcional | [Requisitos v2](../01-planejamento/Requisitos_Steely.md) ([DOCX](../01-planejamento/originais/documento-de-requisitos-v2.docx)) |
| `RNF-01` … `RNF-13` | Requisito não funcional | [Requisitos v2](../01-planejamento/Requisitos_Steely.md) |
| `STY001` … `STY058` | Caso de uso (user story) | [Especificação dos casos de uso](../01-planejamento/Especificacao_de_Casos_de_Uso.md) |
| `STYG` | Caso de uso genérico "Manter Geral" | [Especificação dos casos de uso](../01-planejamento/Especificacao_de_Casos_de_Uso.md) |
| `STY017-RN03` | Regra de negócio nº 03 do caso de uso STY017 | [Regras de negócio](../01-planejamento/Regras_de_Negocio.md) |
| `RB-01` … `RB-15` | Regra de negócio transversal (vale para o sistema todo) | [Regras de negócio](../01-planejamento/Regras_de_Negocio.md) |
| `PRM-xx` | Parâmetro configurável (prazos, limites, valores) | [Regras de negócio](../01-planejamento/Regras_de_Negocio.md) |
| `ADR-01` … `ADR-27` | Registro de decisão de arquitetura | [ADRs](../02-adrs/README.md) |
| `R-xx` | Risco | [Matriz GUT](../01-planejamento/originais/matrizes/README.md) |
| `UC-01` … `UC-18` | Caso de uso **do 1º semestre** (obsoleto) | [Histórico](historico/) |
